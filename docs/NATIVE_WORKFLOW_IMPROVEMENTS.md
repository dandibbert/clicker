# 原生交互改进（2026-10-02）

本轮基于 PR #2（`748171d70f175176c891b5983d0847ea00c72ae6`），保留其九项录制、时序与持久化修复。继续使用原有 SwiftUI 双栏、主题色、原生菜单和设置布局；交互原型仅用于确认操作流程。

## 回放

- 默认 FREE 跨应用自由回放，不自动激活录制时的应用或近期应用。
- 可选 START ONLY：开始前切换到用户选择的正在运行的应用，确认置前后才开始发送输入。只切换一次，不持续锁定应用。失败时必须选择「继续自由回放」或取消，没有隐式 fallback。
- 标题显示动作数、重复轮数和预估时长；无限重复显示单轮时长。
- 不抢焦点的小型控制窗显示脚本名、动作/轮次、停止按钮和 Esc。结束提示区分输入发送完毕、用户停止、准备失败、计时中断；不会把输入发送完毕称为目标业务操作成功。
- 所选单个或多个动作可试运行一次，独立于脚本无限重复。仅展开所选动作，保留其间原有相对时间；任何结束路径都释放按住的输入。
- 回放前检查当前 Core Graphics 显示器范围；支持合法负坐标，不自动平移或缩放。显示器布局变化时应重新检查坐标。

## 编辑与复用

- 添加动作先打开草稿，填写并保存成功后才写入脚本。支持原有七类动作；不再把示例点击坐标或 ⌘C 当成已配置的动作直接添加。
- 保存失败保留表单值并可重试；放弃脏表单需要确认。
- 提供屏幕选点和坐标示意预览，选点覆盖层接收点击，不截屏、不需要屏幕录制授权；Esc 取消。
- 参数修改、动作删除/移动/复制、脚本复制和删除支持应用内撤销/重做（最多保留最近 100 次操作，退出后历史不保留）。撤销写盘失败时不消耗历史，也不提前改变内存库。
- 脚本删除进入持久化的「最近删除」，重启后仍可恢复。没有自动清空或永久删除入口。
- 可见的复制脚本、编辑动作、复制动作入口；跨脚本粘贴产生独立 ID 并保留组内间隔与重叠。

## 脚本库与文件

- 搜索、新建空白脚本、明确空库路径、完整名称悬浮提示。
- 缺少辅助功能或输入监控时，仍可浏览、编辑与导入导出；仅相关录制/回放入口受限。逐项权限状态在回到应用时刷新。
- JSON 导入先预览，默认保留两个；仅同 ID 冲突可明确替换。支持现有 v1–v4 迁移，未知版本及损坏文件给出错误。
- 复制与导入均不继承可自动生效的全局快捷键，也不启用开始前切换应用。导入不会自动运行。
- 常规导出与录制恢复另存使用兼容的 JSON，另存的文件可重新导入。
- 未设置快捷键时显示设置入口，不展示虚构绑定；深色回放轮次使用正文对比度。

## 验证边界

### 空库层级修正

- 空库引导只在右侧内容区显示一次；左侧不再重复图标、说明和新建/录制按钮，空库时也不再显示重复的底部操作条。
- 移除侧栏的大号 Clicker 品牌块，应用名称仍由窗口标题显示。脚本库名称、数量和菜单放在同一紧凑行，下方保留搜索。
- 空库恢复原生录制按钮的红色描边/文字作为主要操作，新建空白脚本保持次要入口；缺少权限时新建仍可用。
- 本次不改主题色值或图标文件。PR #2、此前主分支与 build 28 的主题 token 相同；原图标的米白/炭黑/红色亦保持不变，避免把层级修正扩成另一次主题重做。
- 新增真实 MainView 渲染回归：空库/有脚本、760×480/1000×700、浅色/深色共八种组合，检查唯一空态、紧凑侧栏和保留操作入口，输出 PNG 供目视检查。

- Linux 编辑环境不提供 Swift/macOS SDK；原生编译、测试、渲染和安装启动烟测在 GitHub 的 macOS ARM64 与 Intel runner 上执行。
- 安装烟测使用独立临时库，通过 LaunchServices 环境变量显式开启安全测试模式，启动参数保持为空：创建真实原生窗口，但不注册全局快捷键、不录制、不投递输入，也不请求权限。
- CI 渲染检查覆盖浅/深色、760×480 最低窗口、长名称、辅助字号。模型/引擎测试使用注入的输入投递替身。
- CI 不能代替用户硬件上权限授予/撤销、Spaces/窗口切换、双显示器插拔、中文输入法、真实输入注入与系统安全提示验收。

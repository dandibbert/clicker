# Clicker 紧凑控制区与外观设置设计

## 目标

解决三个已经在实际界面中确认的问题：脚本顶部控制区占用过多纵向空间、录制停止快捷键设置形态陈旧、应用无法手动选择浅色或深色外观。

本次只调整界面密度和设置体验，不改变录制、回放、重复、轮次间隔、快捷键校验或权限行为。

## 紧凑脚本控制栏

采用单行紧凑工具栏，目标高度为 88–104pt，替代当前纵向三段式 Header。

- 左侧显示脚本标题，以及下一行较小的“动作数 · 预计时长”。标题保持单行截断。
- 中间显示录制与回放两个等宽、同层级的主操作。两者继续使用现有共享按钮和状态模型；录制以红色描边表达语义，回放使用中性样式。
- 右侧显示紧凑的重复设置：重复次数、无限开关、轮次间隔。使用短标签和小尺寸输入框，不新增弹出层。
- 播放中的轮次状态在右侧设置区附近显示，不改变工具栏高度。
- 在 760pt 最小窗口宽度下不得裁切。空间不足时，元数据可优先收缩，主操作和可编辑设置必须保持可达。
- Header 下方直接进入动作列表，移除没有信息价值的空白。

## 快捷键录入卡

录制设置页使用单一、整块可点击的快捷键录入卡，不再并列展示“当前快捷键”和单独的“更改快捷键”按钮。

- 空闲状态展示“停止录制快捷键”、当前组合键的独立键帽，以及“点击重新录入”。
- 点击卡片后进入捕获状态，卡片明确显示“请按下新的组合键…”，并提供可见的监听状态，不改变窗口尺寸。
- 捕获成功后立即退出监听并持久化；冲突、修饰键单独输入和裸文本键继续使用现有校验规则。
- 组合键拆成独立键帽展示，例如 `⌃`、`⌥`、`⇧`、`⌘`、`E`，顺序稳定，VoiceOver 仍读取完整组合键。
- “恢复默认值”保留为次要操作；“完成”保留为主要操作。
- 最大辅助功能字号下内容区域可滚动，底部操作始终可达。

## 外观设置

设置页顶部新增“外观”区，使用三段式选择器：

- 跟随系统
- 浅色
- 深色

选择立即作用于所有 Clicker 窗口和设置页，并持久保存到本地偏好。默认值为“跟随系统”，现有用户没有保存值时保持当前行为。

外观偏好使用独立、可注入的存储边界，业务状态只暴露当前选择；SwiftUI 根视图根据选择应用 `preferredColorScheme`。不修改 macOS 系统外观，也不写入系统偏好。

## 视觉规则

- 继续使用已批准的六色色板和动态主题角色，不新增颜色。
- 红色只用于录制、危险操作和活动轨迹。
- 字体继续使用系统 SF 系列。
- 控件密度为紧凑但可点击；键盘焦点、VoiceOver 标签和 Reduce Motion 行为不得退化。
- 快捷键键帽是本次设置页的唯一新视觉 signature，不增加装饰性图形。

## 状态与数据流

- `AppAppearancePreference` 表示 system/light/dark，并负责稳定编码。
- `AppState` 从注入的 preference store 读取初始值；用户改变选择时立即保存。
- `ClickerApp` 或根内容视图将偏好映射到 `ColorScheme?`。
- 快捷键捕获继续通过现有 `RecordingShortcutEditor` 和 `ShortcutCaptureView`；新 UI 只改变呈现和触发方式。
- 脚本 Header 继续通过现有 notification 和 `AppState.update` 修改业务状态。

## 错误与边界行为

- 无法读取外观偏好时回退为“跟随系统”；保存失败不得影响当前会话的即时外观切换。
- 快捷键冲突时保留上一个有效值并显示明确警告。
- 录制或回放期间，既有禁用和设置页 dismissal 行为保持不变。
- 非有限或负数的时长继续使用现有安全格式化。

## 测试与验收

严格执行 RED→GREEN：

- 外观 preference 的默认值、持久化和三档 `ColorScheme` 映射。
- 顶部工具栏的紧凑布局 presentation、录制/回放等权状态、重复与间隔行为。
- 快捷键组合拆分为稳定键帽、捕获状态、成功/冲突/风险提示和 VoiceOver 文案。
- 760×480 浅色/深色渲染确认 Header 无裁切且动作列表获得更多空间。
- 设置页在浅色/深色及最大辅助功能字号下无裁切，底部按钮可达。
- 完整测试、Debug/Release 构建、bundle、图标和签名验证。

真实全局快捷键、录制、回放和实时系统外观切换仍作为人工验收项，不通过测试投递全局输入或修改系统设置。

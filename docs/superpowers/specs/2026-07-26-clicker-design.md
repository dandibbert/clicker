# Clicker — macOS 原生鼠标键盘录制回放工具 设计文档

日期：2026-07-26
状态：已确认

## 概述

Clicker 是一个 macOS 原生 app，用于录制鼠标和键盘的输入操作并回放。核心特性：

- 录制完整时间轴（包括无操作间隔），回放 1:1 重现
- 录制前 3 秒倒数
- 录制结果以类 Shortcuts 动作块形式呈现，可编辑
- 回放可指定重复次数（1 到无限）与每次重复之间的间隔
- 多脚本库，自动保存
- 全局快捷键 + 菜单栏双通道控制

## 技术选型

- 语言/框架：Swift + SwiftUI，目标 macOS 14+
- 构建：Swift Package Manager 可执行目标 + 打包脚本生成标准 `.app`（不使用 Xcode 工程文件）
- 事件捕获：`CGEventTap`（listen-only 模式）
- 事件回放：`CGEvent.post`
- 权限：辅助功能（Accessibility）。首次启动检测并引导用户到系统设置授权。

排除的方案：Electron/Tauri（非原生、体积大）；Hammerspoon/AppleScript（无法做独立 app 与块编辑界面）。

## App 形态

### 主窗口

- 左侧：脚本库列表（可重命名、删除、复制）
- 右侧：所选脚本的动作块编辑器
- 顶部工具栏：录制按钮、回放按钮、重复次数（1 到无限，无限用开关表示）、重复间隔（秒）

### 菜单栏图标

- 常驻菜单栏，提供：开始/停止录制、回放、停止
- 录制/回放时图标变色提示状态

### 全局快捷键

- `⌥⌘R`：开始/停止录制
- `⌥⌘P`：开始/停止回放
- `Esc`：回放期间紧急停止

## 录制引擎

- `CGEventTap`（listen-only）捕获：
  - 鼠标：移动、左/右键按下与抬起、拖拽、滚轮
  - 键盘：按键按下与抬起（含修饰键状态）
- 每个事件带精确时间戳（相对录制起点），完整保留无操作间隔
- 点击"录制"后：主窗口隐藏，屏幕中央显示 3-2-1 倒数浮层，倒数结束开始捕获
- 停止录制时的清理：
  - 停止快捷键的按键事件自动从录制结果中剔除
  - 通过菜单栏停止时，尾部对应的鼠标移动与点击事件自动裁掉

## 动作块模型

原始事件流在录制结束后自动分组为语义化动作块：

| 块类型 | 分组规则 | 显示 | 可编辑参数 |
|--------|----------|------|-----------|
| 鼠标移动 | 连续移动事件合并为一块，内部保存完整轨迹点 | 起点 → 终点、时长 | 终点坐标、时长 |
| 点击 | 按下 + 抬起合并；识别单击/双击/右键 | 类型 + 坐标 | 坐标、按键类型、点击次数 |
| 拖拽 | 按下 → 移动 → 抬起合并为一块 | 起点 → 终点、时长 | 起点、终点、时长 |
| 滚轮 | 连续滚动合并 | 方向 + 总量 | 滚动量 |
| 键盘输入 | 连续普通打字合并为一段文本 | 输入的文本 | 文本内容 |
| 快捷键 | 带修饰键的按键单独成块 | 如 ⌘C | 修饰键 + 主键 |
| 等待 | 超过阈值（0.5s）的无操作时间 | 时长 | 时长 |

小于阈值的间隔隐含在块间，不单独显示，但回放时仍精确重现。

## 编辑器能力

- 修改参数：点开块编辑坐标、文本、时长、按键等
- 删除块
- 拖拽排序
- 新增块："+" 按钮插入 点击 / 键盘输入 / 快捷键 / 等待 / 移动
- 复制粘贴块
- 回放时高亮当前执行的块

## 回放引擎

- `CGEvent.post` 按时间轴重放事件
- 重复次数：1 到无限
- 每次重复之间的间隔：可设置（秒）
- 回放中可随时通过快捷键 / Esc / 菜单栏停止
- 回放期间过滤用户真实输入对回放流的干扰（回放产生的事件不被录制引擎捕获）

## 持久化

- 脚本以 JSON 存储于 `~/Library/Application Support/Clicker/scripts/`
- 每个脚本一个文件，包含：名称、创建/修改时间、动作块数组（含原始轨迹点）、回放设置（重复次数、间隔）
- 编辑操作自动保存

## 错误处理

- 无辅助功能权限：录制/回放按钮禁用，显示引导授权界面，授权后自动恢复
- 事件 tap 被系统禁用（超时/权限变化）：自动重建 tap，失败则停止录制并提示
- 回放中脚本为空或坐标超出屏幕：跳过无效事件，继续执行
- JSON 损坏：跳过该脚本并在列表中标记，不影响其他脚本加载

## 测试策略

- 单元测试：事件流 → 动作块分组逻辑（核心，纯函数易测）；动作块 → 回放事件序列的展开逻辑；JSON 编解码往返
- 手动验收：录制含移动/点击/打字/等待的操作序列，检查块列表正确性；回放验证时序与坐标；无限重复 + 停止；权限缺失流程

## 模块划分

```
Sources/Clicker/
  App/            入口、AppDelegate、菜单栏、全局快捷键
  Recording/      CGEventTap 捕获、倒数浮层、事件清理
  Grouping/       原始事件 → 动作块分组（纯逻辑）
  Playback/       动作块 → CGEvent 序列展开与定时投递（纯逻辑 + 投递）
  Models/         事件、动作块、脚本的 Codable 模型
  Storage/        脚本库的加载/保存
  UI/             主窗口、脚本列表、块编辑器、块参数编辑
```

关键边界：Grouping 与 Playback 的展开部分为纯函数，不依赖系统 API，可独立测试。
